# · What Fedora's repositories do not carry, offered by `./setup packages`
# · after dnf.txt is done. One entry a line of seven tab-separated fields:
#
# ·   type   source   name   consent   required   pins   description
#
# · type     copr, yumrepo, rpm, tarball, source, flatpak, pip-venv, npm or
# ·          optin.
# · source   owner/project for a copr, the URL for the rest, flathub for a
# ·          flatpak.
# · consent  required — asked about once with the registry, and the desk does
# ·                   not go on without what it answers for.
# ·          optional — asked about with it; skipped on a no.
# ·          optin — never installed by a plain install, only said and
# ·                  pointed at; nothing lands unannounced.
# · required yes — when this ends up missing (declined, failed, unavailable)
# ·          the install stops before anything is deployed, with the reason.
# · pins     key=value pairs, comma separated, no spaces around the commas:
# ·            tag= commit=   what a source entry checks out
# ·            sha256=        what a download must hash to, or it is refused
# ·            dest=          where an archive, a file or a repo file lands
# ·            pick=          a file inside an archive, copied to dest= as
# ·                           NAME (inside:outside renames it)
# ·            has=           the file or folder under dest= that answers
# ·                           for the entry once it is there
# ·            fc=            the font family fc-list looks for
# ·            bins=          what a build produced, copied onto the PATH
# ·            cmd=           how a source entry builds, run from its tree
# ·            tool=          the tool that build needs, checked first
# ·            prefix= venv= module=   where npm and pip things live
# ·            baseurl= gpgkey=       a yumrepo's address and its signing
# ·                                   key; a repository whose key impasto
# ·                                   cannot check is never added
# ·            sig=           unsigned, for an RPM that is refused outright
#
# · Whether something is wanted is answered by a person: --noconfirm and a
# · terminal that cannot ask skip the whole registry and say what was skipped,
# · and --noconfirm never counts as a yes. An unsigned RPM is refused, never
# · installed with --nogpgcheck. Nothing is fetched that is not pinned, and
# · a checksum that does not match is refused, not installed. An entry a
# · person installed another way is detected and kept.
